# 🤖 NewsBot Constructor & Host (Конструктор и хостинг новостных ботов)

Мощная модульная система на **Python 3** и **aiogram 3**, позволяющая на одном ПК/сервере создавать, хостить и тонко настраивать независимых Telegram-ботов для администраторов новостных каналов.

Проект спроектирован на базе проверенных решений из **TeakBot** (обработка медиа-альбомов с задержкой сборки, антифлуд, система банов, модерация предложки и связь с авторами), но расширен до полноценной фабрики ботов с многопользовательским хостингом.

---

## 🌟 Основные возможности

### 1. 🏭 Хостинг ботов на вашем ПК / сервере (Multi-Bot Engine)
- Все созданные боты работают **внутри единого асинхронного процесса** через динамический `BotManager`.
- Боты запускаются, останавливаются и перезапускаются на лету через интерфейс главного бота без перезапуска всей системы.
- Изоляция ошибок: если один бот отзовет токен или столкнется с ошибкой, остальные боты и мастер-бот продолжат бесперебойно работать.
- Автоматический перезапуск всех активных ботов при старте скрипта или перезагрузке сервера.

### 2. 📝 Постинг со всеми тегами и полным форматированием
- **Сохранение разметки Telegram (HTML Entities)**: жирный, курсив, зачеркнутый, ссылки, спойлеры, цитаты (`blockquote` и `expandable blockquote`), кастомные эмодзи и код.
- **Интерактивный выбор тегов (рубрик)**: выбор из настроенных рубрик канала (`#срочно`, `#технологии`, `#крипта` и т.д.), возможность отправить новость без тега или создать свой тег прямо на лету.
- **Поддержка любых медиа**:
  - Одиночные фото, видео, GIF-анимации, документы, кружочки/голос.
  - **Альбомы (Media Groups)** из нескольких фото и видео (сборка с таймером 1.0 сек, как в TeakBot).
- **Интерактивное превью перед выходом**: бот присылает точный вид поста автору в ЛС перед публикацией.
- **Инлайн-кнопки**: возможность прикрепить URL-кнопку к конкретному посту (например, *«Читать источник»*) или задать постоянную кнопку по умолчанию.
- **Отложенный постинг**: планирование публикации через N минут с автоматической очередью в БД.

### 3. ⚙️ Тонкая настройка каждого бота
- **Водяной знак / Подпись**: настройка индивидуальной подписи для каждого канала с поддержкой макроса `{tag}`.
- **Шапка и подвал**: автоматическая вставка заголовков (например, `⚡️ СРОЧНО | {tag}`) и подвала.
- **Режимы работы**:
  - `Прямой постинг`: доступ только администраторам и редакторам.
  - `Предложка (модерация)`: подписчики присылают новости, а редакторы одобряют в 1 клик, отклоняют, банят спамеров или пишут автору в ЛС.
- **Предпросмотр ссылок**: включение или отключение генерации превью сайтов.
- **Беззвучный режим**: отправка в канал без звукового уведомления (`silent_mode`).
- **Защита контента**: запрет на пересылку и сохранение медиа из канала (`protect_content`).
- **Кулдаун (антифлуд)**: ограничение частоты отправки постов для защиты от спама.
- **Управление командой**: добавление редакторов по их Telegram ID.

## 📂 Структура проекта

```
newsbot_constructor/
├── config.py              # Конфигурация мастер-бота и хостинга
├── database.py            # Асинхронная БД SQLite (боты, настройки, теги, админы, отложка)
├── publisher.py           # Движок сборки постов, форматирования и отправки в канал
├── client_bot.py          # Логика и обработчики клиентских ботов (постинг, превью, модерация)
├── manager.py             # BotManager (динамический запуск, остановка, пул ботов, планировщик)
├── master_bot.py          # Логика главного бота-конструктора (мастер создания, меню настроек)
├── main.py                # Точка входа сервера-хостинга
├── requirements.txt       # Зависимости Python
└── .env                   # Переменные окружения (токен мастер-бота)
```

## 🚀 Быстрый запуск

### 1. Подготовка окружения
Перейдите в папку проекта:
```bash
cd /home/qualbyy/.gemini/antigravity/scratch/newsbot_constructor
```

Используйте существующий виртуальный venv (например, из TeakBot) или создайте новый:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
nano .env
```
Укажите:
- `MASTER_BOT_TOKEN`: токен главного бота-конструктора, полученный у [@BotFather](https://t.me/BotFather).
- `SUPERADMIN_ID`: ваш числовой Telegram ID (можно узнать у [@userinfobot](https://t.me/userinfobot)).

### 3. Запуск
```bash
python3 main.py
```
*(Или `/home/qualbyy/TeakBot/venv/bin/python main.py`)*

## 🛠 Автозапуск 24/7 (systemd service на Linux)

Чтобы хостинг работал постоянно в фоне и поднимался при включении ПК/сервера:

1. Создайте unit-файл службы:
```bash
sudo nano /etc/systemd/system/newsbots.service
```

2. Вставьте конфигурацию:
```ini
[Unit]
Description=Telegram NewsBot Constructor and Hosting Service
After=network.target

[Service]
Type=simple
User=qualbyy
WorkingDirectory=/home/qualbyy/.gemini/antigravity/scratch/newsbot_constructor
ExecStart=/home/qualbyy/TeakBot/venv/bin/python main.py
Restart=always
RestartSec=5
StandardOutput=append:/home/qualbyy/.gemini/antigravity/scratch/newsbot_constructor/constructor.log
StandardError=append:/home/qualbyy/.gemini/antigravity/scratch/newsbot_constructor/constructor.log

[Install]
WantedBy=multi-user.target
```

3. Активируйте и запустите службу:
```bash
sudo systemctl daemon-reload
sudo systemctl enable newsbots
sudo systemctl start newsbots
```

Проверить статус работы:
```bash
sudo systemctl status newsbots
```

## 📖 Как пользоваться

1. Откройте вашего главного бота в Telegram и отправьте `/start`.
2. Нажмите **➕ Создать бота**:
   - Введите токен нового бота от [@BotFather](https://t.me/BotFather).
   - Укажите канал (например, `@my_channel`), предварительно добавив созданного бота администратором канала с правом отправки сообщений.
   - Выберите режим: *Прямой постинг* или *Предложка*.
3. Бот мгновенно запустится на хостинге!
4. В разделе **⚙️ Настройки публикации** можно:
   - Настроить водяной знак, шапку и подвал.
   - Добавить рубрики/теги (например `#новости`, `#инсайд`).
   - Назначить других редакторов по их Telegram ID.
5. Откройте созданного бота и просто отправьте в него новость: выберите тег, оцените превью и нажмите **🚀 Опубликовать в канал**!
